# hfzip

In this directory, you should write the program `hfzip.c` and compile it into the binary `hfzip` (e.g., `gcc -o hfzip hfzip.c -Wall -Werror`)(e.g., `g++ -o hfzip hfzip.cpp -Wall -Werror`).

After doing so, you can run the tests from this directory by running the `test-hfzip.sh` script. If all goes well, you will see:

```sh
prompt> ./test-hfzip.sh
test 1: passed
test 2: passed
test 3: passed
test 4: passed
test 5: passed
test 6: passed
prompt>
```

The `test-hfzip.sh` script is just a wrapper for the `run-tests.sh` script in the `tester` directory of this repository.
